## 👍 스터디 방식

- 매주 선정된 발표자 1명은 문제 풀이 또는 해당 주제와 관련된 심화 내용 미니 세미나를 진행합니다.
- 모든 스터디원은 공부한 내용을 아티클로 작성하고, 월요일 23:59까지 PR 또는 링크로 제출합니다.
- 스터디 전까지 최소 3명 이상의 아티클에 배운 점, 질문, 피드백 등을 댓글로 남깁니다.
- 발표자는 스터디 전날까지 PR로 퀴즈를 출제합니다.
- 모든 스터디원은 스터디 전까지 PR 리뷰로 퀴즈 풀이를 남깁니다.

## 📝 제출 규칙

### 🌳 브랜치

- 본인의 주차별 브랜치를 생성하여 작업합니다.
- 브랜치 이름: `week주차/이름`
- 예시: `week1/yumin`
- 작업을 마친 뒤 commit 및 push하고, `main` 브랜치로 PR을 보냅니다.

### 📁 폴더 및 파일

파일명과 세부 폴더 구조는 자유롭게 정하되, 본인 디렉토리 안에서 작업해주세요.

- `docs/`: 공부한 내용이나 관련 아티클을 정리하는 폴더
  - Markdown 파일로 작성합니다.
  - 노션이나 블로그 링크를 Markdown 파일에 적어 제출해도 됩니다.
- `quiz/`: 주차별 퀴즈를 출제하는 폴더

경로 예시:

- `docs/yumin/week1/README.md`
- `quiz/yumin/week1/quiz.md`

### 📝 Pull Request

- 제목 예시: `[Week1/김유민] 변수, 함수, 스코프 퀴즈 (4장, 12~15장)`
- 발표자는 퀴즈를 최소 4~5개 출제해주세요.
- 퀴즈 제출 시 PR 본문에 퀴즈를 작성해주세요.
- `main` 브랜치로의 merge는 스터디가 끝난 뒤 일괄 진행합니다.
